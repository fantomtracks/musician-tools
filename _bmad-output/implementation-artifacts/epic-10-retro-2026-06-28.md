## 🔁 Lessons
1. **Un nouveau flux peut réveiller un effet dormant.** 10.2 a fait muter `playlists` en pleine édition (`setPlaylists`), réveillant un `useEffect` de seed inerte jusque-là → clobber de `selectedPlaylistUids`. **Règle :** quand un nouveau chemin écrit dans un state dont dépend un effet existant, **auditer cet effet** (deps + idempotence).
2. **Un test de régression non vu rougir ne prouve rien.** Le 1ᵉʳ test « anti-clobber » était tautologique (il ne voyait que la frame transitoire — même piège que le test AC8 d'origine). Fix : **settler les effets** avant d'asserter, **et vérifier que le test échoue sur le code pré-fix** (fait par `git stash`). C'est devenu une exigence (cf. action item #2).
3. **Anti-tapis tenu.** Les findings de review non corrigés (parité afterSync, anti-double-submit, cosmétique) sont **tous** consignés en deferred-work, aucun enterré silencieusement.
