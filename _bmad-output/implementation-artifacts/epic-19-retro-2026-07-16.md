## 🔎 Défis & leçons

1. **🐛 StrictMode double-mount, ENCORE (bouton Add figé). — LEÇON PRIORITAIRE**
   19-4 : le bouton *Add to my songlist* restait `disabled` à l'infini alors que le back renvoyait 201. Cause : `mountedRef` posé une fois à l'init, **jamais ré-armé** au remount StrictMode → le `setState` de la réponse était ignoré. Débusqué en **QA**, pas en CI.
   **Leçon : c'est exactement l'action item D d'Epic 18 — la règle était bonne, le bug est passé parce que le test n'était pas sous StrictMode _à ce moment-là_. → Généraliser : TOUS les nouveaux tests composant sous `<StrictMode>` par défaut (pas seulement Songs). L'action A d'Epic 18 doit couvrir tout le repo.**

2. **🐛 Largeur qui « bouge » = `mx-auto` sur enfant flex, PAS la scrollbar. — LEÇON PROCESS PRIORITAIRE**
   Le conteneur `max-w-5xl mx-auto` est un enfant de `<main class="flex flex-col">`. Or `mx-auto` sur un enfant flex le fait **se dimensionner au contenu** (shrink-to-fit) : large avec la table, étroit avec « No entries ». Fix = `w-full`.
   **Double leçon :** (a) pour un conteneur centré qui « suit le contenu » dans un parent flex → **suspecter le shrink-to-fit de `mx-auto`, poser `w-full`** ; (b) **j'ai brûlé ~5 itérations à théoriser sur la scrollbar à l'aveugle** avant de demander un screenshot. **Repro visuel AVANT hypothèse** sur tout bug de layout — le screenshot du 3ᵉ état (0 résultat) a tranché en 30 s ce que 5 tours de devinette n'avaient pas trouvé.

3. **🎭 La QA a lourdement remodelé l'UX APRÈS une review 9/9 AC verte.** Multi-sélection type Songlist, delete-in-fiche, form réordonné (artiste avant titre), bandeau 409 repositionné, layout stabilisé — tout ça **post-review**. La suite auto (406✓) et la review 3 couches valident la **correction**, pas le **ressenti**.
   **Leçon (déjà vue en 18) : pour une story UI-lourde, budgéter la QA manuelle comme une phase à part entière — elle _reshape_ l'UX, ce n'est pas du polish optionnel.**

4. **🔧 Friction outillage : `make db-restore` ne lit pas un dump prod récent.** Le dump prod est fait par `pg_dump 17` (format 1.16), mais le container `db` local est **postgres:15** → son `pg_restore` échoue (`unsupported version`). Contourné avec un client `postgres:17`.
   **Leçon : le `db-restore` du Makefile doit utiliser un client `pg_restore` de version ≥ serveur prod, sinon le refresh casse à chaque montée de version PG côté prod.**

5. **🧱 Dette naissante : le pattern multi-sélection est dupliqué.** `CatalogManage` réplique inline le pattern de `SongsList` (checkboxes + select-all + barre « Delete selected » + clic-ligne = ouvrir). Pas de composant partagé.
   **Leçon : motif dupliqué à 2 endroits = signal (cf. rendu session Epic 8/9). À trancher à la prochaine revue `deferred-work` : extraire un composant multi-select réutilisable, ou l'assumer.**
