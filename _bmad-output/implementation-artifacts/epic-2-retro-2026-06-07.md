## Défis et leçons

1. **🕳️ La saga de l'octet NUL (5 incidents)** — l'écriture de séquences `\uXXXX` via l'outillage d'édition produit des NUL bruts (2 contrôleurs, 1 test, 1 markdown « binaire » dans git, 1 commande shell). Leçons : double-échappement systématique + scan `perl -ne 'exit 1 if /\x00/'` après toute édition concernée + **vérifier dans les deux sens** (la sur-correction 2.4 a créé des gardes comparant au TEXTE `\x00`, mortes à l'exécution).
2. **🧪 Un test vert ne vaut que ce qu'il exerce réellement** — 168 tests verts cachaient les gardes NUL mortes (aucun test n'envoyait un vrai NUL au PUT). Parades adoptées : payloads avec `String.fromCharCode(0)`, assertions des options réelles (`{ transaction }` réellement passé), tests des deux directions d'un comportement.
3. **📋 Un spec peut se contredire lui-même** — en 2.5, prefill et Recent définissaient « récent » différemment (createdAt vs date). Les couches blind/edge l'ont vu parce qu'elles lisent le code sans préjugé.
4. **🖥️ Le fossé jsdom ↔ navigateurs réels** — (a) jsdom applique la validation native min/max (découvert en 2.1) ; (b) **Safari laisse taper du texte dans `type="number"`** (retour terrain northwood, cette rétro). Leçon : test manuel Safari/Chrome obligatoire avant de clore une story de formulaire.
