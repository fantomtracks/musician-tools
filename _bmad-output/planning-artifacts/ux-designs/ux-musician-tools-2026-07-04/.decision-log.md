## Contexte technique confirmé (lecture code 2026-07-04)

- `SongsList.tsx:123` — conteneur `flex flex-col lg:flex-row gap-6 items-start` → sidebar filtres empilée au-dessus de la liste sous **`lg` (1024px)**.
- `SongsList.tsx:202` — colonne contenu `flex-1` **sans `min-w-0`** → gotcha flexbox : le tableau force la largeur et fait déborder la page.
- Aucun conteneur `overflow`/`max-h` autour du tableau → il allonge toute la page au lieu de scroller en interne.
- `SongForm.tsx:624` et `:697` — `grid grid-cols-3 gap-4` **sans breakpoint** → 3 colonnes serrées même à 390px (vue édition).
- Save-bar édition : `Songs.tsx:1815` `sticky top-16 z-20` (posée en 13-1) — à préserver, vérifier qu'elle ne déborde pas.

## Décisions tranchées (northwood, 2026-07-04)

- **D1 — Portée** : liste + filtres **ET vue édition** (SongForm). On audite aussi les champs qui débordent, la save-bar sticky et le playlist picker sur mobile.
- **D2 — Modèle de scroll du tableau** : **tableau plafonné (~65vh) à scroll interne**. Recherche + filtres restent visibles au-dessus ; la page ne s'allonge plus. Vaut desktop + mobile. En-tête de colonnes `sticky` dans la zone de scroll.
- **D3 — Filtres sur mobile** : **disclosure « Filters » replié par défaut** sous le breakpoint ; les chansons sont visibles immédiatement, tap pour déplier. Sur desktop (`lg+`) la sidebar reste affichée telle quelle.
- **D4 — Colonnes en écran étroit** : **scroll horizontal, tableau conservé**. Toutes les colonnes gardées ; le tableau scrolle latéralement dans SON conteneur ; les autres blocs ne débordent plus grâce à `min-w-0`. Pas de reflow en cartes (report assumé).

## Décisions dérivées / à acter au cadrage

- **D5 — Breakpoint de bascule** : réutiliser **`lg` (1024px)** déjà en place pour la bascule sidebar↔empilé. Le disclosure filtres (D3) s'active donc sous `lg`. Cohérent avec `SongsList.tsx:123` — pas de nouveau seuil introduit.
- **D6 — Compteur de filtres actifs** : le bouton disclosure affiche le **nombre de filtres actifs** (« Filters · 2 ») pour ne pas cacher un filtrage en cours quand il est replié.
- **D7 — État du disclosure** : replié par défaut à chaque visite (pas de persistance) — cohérent avec un usage « je viens chercher une chanson », les filtres sont l'exception.
- **D8 — Grille SongForm** : `grid-cols-3` → `grid-cols-1 sm:grid-cols-3` (empile sous `sm`, 3 colonnes dès `sm+`). Applique aux 2 grilles (`:624`, `:697`).
